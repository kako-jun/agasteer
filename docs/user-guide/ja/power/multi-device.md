# 複数デバイスでの同期

PC、スマホなど複数デバイスで使う場合の注意点です。

---

## 基本的な流れ

1. **デバイスA**で編集 → Push
2. **デバイスB**でPull → 編集 → Push
3. **デバイスA**でPull → ...

---

## 注意

- 衝突したとき、変更が重なっていなければ「両方の変更をマージして解決する」で両方を残せます（[両方の変更をマージする](../basics/sync.md#両方の変更をマージする)）
- 同じ行を両方のデバイスで編集したなど、変更が重なっているときは自動ではマージしません。どちらかで上書きすると、もう片方の変更は失われます
- 編集前にPullしておくと、衝突そのものを減らせます

---

## Stale警告

別デバイスで編集された場合、Push前に警告が表示されます。

- 上書きするか、先にPullするか選べます（変更が重なっていなければ、両方をマージすることもできます）
- 5分間隔でバックグラウンドチェックも行われます
